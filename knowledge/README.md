# knowledge/

This folder intentionally ships **empty**.

Domain knowledge notes are created by `/domain-tutor` (Claude Code) or `/tutor` (Windsurf)
into `.agent/knowledge/` **inside the project you're working in** — for work-derived
knowledge, that means the work machine, not this personal repo.

The only notes that belong here are fully generic ones you'd be comfortable publishing:
general telecom/networking concepts, Spring patterns, AI-engineering lessons — written in
your own words, containing zero employer code, wiki content, or product internals.

Template: `../domain-tutor/assets/knowledge-note-template.md`.
